AI key setup (for grown-ups)

KenyAI's tutors (Kuku, Kobe, Twiga, Tembo and Turi) already work through the KenyAI relay, which holds a Claude key on a server. Add your own Claude API key here if the relay is busy or you want the AI to use your account.

Where the key is kept

  • It is saved in this browser on this device only (browser storage for this website). It stays until you press "Forget", or until someone clears the browser's site data.
  • Every KenyAI page on this device uses it: the home page, the learning path and Jambo Letters.
  • It is never put in the website files or the GitHub repo. The repo is public, and GitHub automatically reports Claude keys found in public code to Anthropic, which switches them off. A key in the repo would stop working within minutes.
  • Do this once on each phone or computer the children use. On a shared device, anyone using that browser can use the key, so set a monthly spending limit in the Anthropic Console.
